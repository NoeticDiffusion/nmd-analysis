- **Preprocessing parity: PASS.** Hash-identical raw inputs and fixed windows produced PCV/TP/OI/SC values within the declared tolerance; maximum absolute difference was 9.72e-17. Historical filtered arrays were not retained, so only measurement-value parity is established.
- **Corrected six-person extraction: PASS.** 7,776 four-second fast-core windows and 648 full-v3 20-second windows were emitted. All ten post-run checks passed; historical full-v3 values matched exactly. No classifier or full cohort was run.
- **Temporal synthetic screen: PASS for its frozen TP generator only.** Four prespecified screens passed. This does not resolve empirical support/QC or qualify other metrics.
- **Reference sensitivity: COMPLETE, descriptive.** Core19 average-versus-linked-mastoid median absolute differences are approximately 0.12 for PCV and 0.32–0.55 for RD across 4–20 seconds (six participant-level medians). Alternative references must remain separately identified. No equivalence claim is supported.
- **Temporal QC: NOT RESOLVED.** Source bad-interval status is unknown, and effective edge support for the MNE resample, notch, and zero-phase bandpass chain is unquantified. This is the remaining sl_027 readiness blocker.

The reference pilot used 61 fixed anchors from continuous BIDS `task-rest` files. It did not interpret these as physiological rest and did not read task labels. Its outputs are unqualified. Every MNE-resampled file had one fewer terminal sample than its V002 polyphase counterpart, but all frozen anchor windows fit; the branches remain separate.
