## Updated interpretation

The cleanest claim is now:

> Across ANPHY and BOAS, spindle events produce a reproducible within-event increase in `d_n` relative to pre-spindle baseline. Event-control specificity is broader and partly baseline-dependent. However, pre-event embodied-anchor measures — cardiac/vagal in ANPHY and respiratory in BOAS — do not currently moderate the spindle-linked geometry effect.

That is a disciplined result.

## What the `d_n` decomposition means

The `d_n` story is now much clearer:

```text
A = event − pre_far
```

is positive in both datasets.

```text
B = pre_far − matched_control
```

differs by dataset.

So the timing result is stable, while the specificity result depends on how peri-spindle baseline compares to matched generic N2. That means `d_n` should be written as:

> a robust **peri-spindle timing effect**, with matched-control specificity complicated by dataset-specific N2 baseline structure.

Not:

> a simple universal event-control specificity effect.

## Pass B: run it, but constrain the interpretation

Pass B should answer only:

> Does putting anchor variables into the coordinate surface change the spindle-geometry results?

It should **not** answer:

> Does EAP moderation exist?

That question was Pass C, and the answer is currently no.

### Pass B recommended outputs

For both ANPHY and BOAS, compare primary vs anchor-augmented surfaces for:

```text
A1r event − matched_control
A2r event − pre_far
```

Use the same subject-weighted estimator as A1r/A2r.

For each endpoint, report:

```text
primary_delta
anchor_aug_delta
surface_delta = anchor_aug_delta − primary_delta
correlation(primary_delta, anchor_aug_delta)
sign agreement
FDR status change
```

Primary focus should be:

```text
e
e_m
d_n
e_s
d_s
```

Because `e_m` is the coordinate directly changed by anchor augmentation, and `e` may inherit that change through recomposition.

## Guardrail for Pass B

If anchor-augmented surfaces produce stronger effects, do **not** interpret that as EAP confirmation.

The correct interpretation would be:

> Anchor-augmented coordinates are sensitive to body-derived signals when those signals are injected into the geometry. This does not imply that pre-event anchor state moderates EEG-only spindle geometry.

That distinction is crucial.
