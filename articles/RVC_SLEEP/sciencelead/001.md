# 001 · Protocol amendment: subject-weighted primary estimand for Pass A1 (and A2/C)

**Date:** 2026-07-03
**Decision by:** science lead, in response to the BOAS A1 heterogeneity audit
(diary 227). Recorded here per the sister article's `sciencelead/00N.md`
convention, before any Pass A1 table was overwritten.

## Decision

**(b)** — adopt an equal-subject-weight estimand as the corrected primary for
Pass A1, applied identically to ANPHY and BOAS. This is a written protocol
amendment, not a BOAS-only rescue.

## Reason

The scientific question was never really:

> Do all spindle events, pooled across subjects, differ from controls?

It is:

> Do subjects show spindle-specific geometry effects on average?

Subject is the biological unit in a dual-dataset human sleep study. BOAS has
sparse and uneven spindle counts (median 5/subject, range 1–18, vs. ANPHY's
median 40/subject, range 3–66), so the original event-weighted cluster-robust
OLS overrepresents high-event subjects. The heterogeneity audit (diary 227)
showed this specifically distorts `d_n`, `d_s`, `e_s` — not all endpoints
indiscriminately — which is exactly the kind of endpoint-specific finding that
justifies locking a subject-weighted estimand rather than cherry-picking a
rescue.

## What does NOT change

The original Pass A1 table
(`results/rvc_sleep_20260702/02_pass_a1_rvc_specificity/pass_a1_rvc_specificity.csv`,
produced by `src/02_pass_a1_rvc_specificity.py`) is **not overwritten**. It is
relabeled in status, not in content:

```text
A1-original-event-weighted  →  pre-amendment sensitivity analysis
```

This preserves the audit trail (category-drift discipline: a corrected primary
does not retroactively erase what the original analysis actually found).

## Corrected primary estimator ("A1r")

For each dataset and each of the 9 frozen endpoints:

```text
event_control_delta = event_bin_geometry - median(matched_control_geometry)   [same as A1-original]
subject_mean_delta  = mean(event_control_delta within subject)
```

Primary test: `subject_mean_delta ~ 1`, tested via **subject-level sign-flip
permutation** (chosen as the single formal primary p-value — robust,
non-parametric, matches the within-subject direction question). One-sample
t-test and Wilcoxon signed-rank are reported as sensitivity, not primary.
BH-FDR applied across the same frozen 18-test family (9 endpoints × 2
datasets), computed fresh on the permutation p-values (this is a different
estimand from A1-original, so it gets its own multiplicity correction, not a
re-labeling of the old q-values).

Implementation note: this reuses the exact machinery already built for
A1-original's sensitivity tiers (`subject_level_sensitivity`,
`sign_flip_permutation_test` in `rvc_sleep_support.py`) — those functions
already aggregate to one-row-per-subject before testing, so A1r is a
reorganization of existing code into its own primary-status table
(`src/02c_pass_a1r_subject_weighted_specificity.py`), not new statistics.

Applied identically to ANPHY and BOAS — no dataset-specific special-casing.

## A2 gets a lighter, matching amendment ("A2r")

Same sparse/uneven-count concern applies to A2's peri-spindle profile (row
counts per subject differ). Added a subject-balanced companion test, scoped to
the single contrast that carries A2's headline timing claim (event vs.
`pre_far`), for the same frozen 9 endpoints:

```text
within_spindle_delta = event_bin - mean(pre_far bins for same event)
subject_mean_delta   = mean(within_spindle_delta within subject)
```

tested the same way (sign-flip permutation primary, t-test/Wilcoxon
sensitivity, fresh BH-FDR across the 18-test family).
`src/03b_pass_a2r_subject_balanced_profile.py`. The full multi-contrast
MixedLM profile in `03_pass_a2_peri_spindle_profile.py` remains as-is — A2r is
a targeted robustness check on the specific `d_n`/`e_s` timing claim, not a
replacement of the full profile.

## Pass C inherits the same estimand (design only — not run yet)

Updated the Pass C skeleton (`src/05_pass_c_eap_moderation.py`) to specify,
ahead of running it:

- primary model: `event_control_delta ~ anchor_pre_far + covariates`, weighted
  by `1 / n_events_subject` (equivalent in expectation to a subject-balanced
  design), cluster-robust SE by subject;
- subject-level slope sensitivity: fit `slope(event_control_delta ~
  anchor_pre_far)` within each subject, then test whether slopes differ from 0
  across subjects — prevents high-event-count subjects from dominating the
  moderation estimate the same way they did in A1-original.

Pass C is not executed in this pass. Per the science lead's own sequencing
("rerun A1r/A2r once, then move to Pass B/C"), it waits for an explicit
go-ahead once A1r/A2r results are reviewed.
