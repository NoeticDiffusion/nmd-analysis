## Why A1r `d_n` and A2r `d_n` can disagree

A2r tests:

```text
event − pre_far
```

A1r tests:

```text
event − matched_control
```

So if ANPHY has:

```text
event − pre_far > 0
event − control < 0
```

then necessarily:

```text
pre_far − control << 0
```

That means ANPHY’s matched controls may sit at a higher baseline `d_n` than the spindle event’s own pre_far period. That is not necessarily a failure, but it changes the interpretation: the spindle produces a within-event `d_n` rise, but the whole peri-spindle neighborhood may differ from generic matched N2 controls.

So I would ask the implementer to run:

```text
02d_pass_a1_decomposition.py
```

with:

```text
A = event − pre_far
B = pre_far − matched_control
C = event − matched_control
C ≈ A + B
```

for all frozen endpoints, but focus reporting on:

```text
d_n, e_s, d_s, m
```

This should be quick and should not block Pass C for long.

| Delta             | Question                                                                    |

| `event − control` | Does anchor state predict spindle-specific geometry relative to matched N2? |

For RVC, the second may be cleaner. For specificity, the first is stricter.
