# RVC_SLEEP Results Memo — 001 (2026-07-03)

**Status: Pass A / A1r / A2r / decomposition / B / C frozen.** See
`frozen_evidence_summary_20260703.md` (same directory) for the full
evidence table, claim ledger, and limitations this memo summarizes.

## Headline

> A subject-balanced spindle-timing effect is reproducible across ANPHY and
> BOAS, led by `d_n`. Specificity against matched N2 controls is broader and
> baseline-sensitive. Embodied-anchor moderation is not supported.

## What we found, in order of confidence

1. **Spindle events show a reproducible increase in `d_n` relative to their
   own pre-spindle baseline, in both datasets** (A2r subject-balanced timing
   test: ANPHY +0.106, q=0.009; BOAS +0.165, q=0.011). This is the strongest,
   cleanest result in the study and the one the manuscript should lead with.
   `e_s` shows the same pattern but weaker (BOAS confirms, q=0.011; ANPHY
   trends, q=0.062).

2. **Spindle events also differ from matched non-spindle N2 controls on most
   of the 9 frozen endpoints** (A1r, subject-weighted: 8/9 same-sign across
   datasets, most FDR-significant). But this specificity result is **broader
   and less clean** than the timing result: a targeted decomposition
   (`event−control = (event−pre_far) + (pre_far−control)`) shows that for
   `d_n` specifically, the two datasets agree on the timing component but
   disagree on how the pre-spindle baseline itself compares to matched
   generic N2 — which is why `d_n`'s A1r sign flips between datasets while
   its A2r timing sign does not. For `d_s` and (less cleanly) `m`, the A1r
   effect is mostly a baseline-separation effect, not a timing effect at all.
   **Practical implication for the manuscript: report A1r specificity as
   "broad and present but baseline-sensitive," not as a single clean
   mechanism, and let `d_n`/`e_s` timing (A2r) carry the primary claim.**

3. **Embodied-anchor (HRV / respiratory) moderation of the spindle-linked
   geometry effect is not supported.** Pass C tested this directly (delta ~
   anchor + nuisance covariates, weighted by inverse subject event-count,
   cluster-robust SE, plus a subject-level-slope sensitivity immune to
   event-count imbalance) across both delta definitions and 3 anchor models
   — 54 tests total. 53/54 do not survive FDR. The one exception (ANPHY
   `d_l`, HRV anchor, event-control delta) survives the pooled model's FDR
   but fails its own subject-level slope sensitivity check, and is treated
   as a non-robust pooled-model artifact rather than evidence for
   moderation. **This is reported as a genuine negative result**, consistent
   with the sister gambling article's "EAP-compatible, not EAP-confirming"
   framing — not a failure of the analysis.

4. **Anchor-augmented geometry behaves as a construction-validity check
   would predict, and does not rescue or change the moderation conclusion.**
   Only `e_m` (the coordinate anchor injection directly touches) and `e`
   (which recomposes from `e_m`) show any sensitivity to surface choice; the
   other 7 endpoints are numerically identical between surfaces. No
   endpoint's FDR-significance status changes between the primary and
   anchor-augmented surface, in either dataset or delta mode (0/36 testable
   comparisons). Per the explicit guardrail: this shows the surface is
   sensitive to injected body signals where expected, it does **not** imply
   pre-event anchor state moderates EEG-only spindle geometry.

## Known limitations (see full summary for details)

- BOAS Pass C primary-anchor model runs on a restricted N (~35/128
  subjects); the larger-N sensitivity anchor model is still null.
- BOAS has sparse, uneven spindle-event counts per subject (median 5, range
  1–18) — this motivated the subject-weighted protocol amendment; the
  original event-weighted OLS is kept only as a pre-amendment sensitivity
  table.
- `frequency_hz` and sigma-power residualization are not available in the
  current NMD event-locked schema; not silently substituted, flagged as
  open follow-ups.
- One Pass C row (ANPHY `d_l`) survives pooled FDR but fails its own
  subject-level sensitivity check; documented rather than omitted.
