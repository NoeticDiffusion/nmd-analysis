## Frozen outcome language

Set before any part2 dump is opened.

* **Joint confirmation:** both Holm-adjusted tests pass and both
  directions match the freeze (\(d_{\mathrm{eff}}\) CPC1 > CPC5,
  \(G_{90}\) CPC1 < CPC5).
* **Partial confirmation:** one endpoint passes Holm in the frozen
  direction, the other does not.
* **Directional but unconfirmed:** neither passes Holm, but both point
  in the frozen directions.
* **Failure/reversal:** one or both materially reverse direction.

Same-direction without Holm is not replication.
