# sciencelead/

Science-lead verdicts and go/no-go recommendations for article development.

Typical contents:
- `NNN.md` - one science-lead note per decision point (go/no-go on a paper branch, framing recommendations, prioritisation of primary vs. secondary analyses).

Suggested header for a new science-lead note:

```
# Verdict

## Green light for a paper branch
[Yes / No / Conditional - why]

## Primary vs. secondary framing
## Required robustness checks before submission
## Open questions
```
